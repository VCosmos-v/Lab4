# Задание 1

## Задача 11

### Текст задачи

Составить программу, которая формирует список L, включив в него по одному разу элементы, 
которые входят одновременно в оба списка L1 и L2.

### Алгоритм решения

С помощью цикла обходим все элементы первого списка L1

Для каждого текущего элемента проверяем два условия:

1 содержится ли он во втором списке L2

2 отсутствует ли он еще в результирующем списке L, чтобы избежать дубликатов

Если оба условия выполняются, добавляем элемент в результирующий список.

Возвращаем сформированный список L.

# Задание 3

## Задача 11

### Текст задачи

Есть перечень торгово-развлекательных центров (ТРЦ) города. Студенты группы любят посещать 
ТРЦ. Известно для каждого студента, в каких ТРЦ он побывал. Определить:  
• в какие ТРЦ из перечня ходили все студенты группы;  
• в какие ТРЦ из перечня ходили некоторые студенты группы;  
• в какие ТРЦ из перечня не ходил ни один из студентов группы?

### Алгоритм решения

Создаем три объекта класса HashSet<string> для классификации ТРЦ:

visitedAll

visitedSome

visitedNone

В цикле по каждому студенту выполняем операции над множествами:

пересечение (IntersectWith) для нахождения ТРЦ, посещенных абсолютно всеми

объединение (UnionWith) для нахождения ТРЦ, посещенных хотя бы одним студентом

вычитание (ExceptWith) для определения ТРЦ, в которых никто не побывал

Выводим результаты для каждой категории

# Задание 5

## Задача 11

### Текст задачи

В соревнованиях по многоборью (из M видов спорта) участвуют N спортсменов (N< 1000) .На 
вход программе в первой строке подается число спортсменов N, во второй – число видов спорта 
M. В каждой из последующих N строк находится информация в следующем формате: 
<Фамилия><Имя><Баллы> 
где <Фамилия> – строка, состоящая не более, чем из 20 символов без пробелов, <Имя> – строка, 
состоящая не более, чем из 12 символов без пробелов, <Баллы> –Mцелых чисел, обозначающие 
количество баллов, набранных спортсменом в каждом из видов многоборья. 
<Фамилия> и <Имя>, <Имя> и <Баллы>, а также отдельные числа в поле <Баллы>разделены 
ровно одним пробелом. Пример входных строк: 
3 
4 
Иванов Сергей 100 30 78 13 
Петров Антон 90 16 98 14 
Сидоров Юрий 100 70 30 21 
Программа должна выводить результирующую таблицу, содержащую список спортсменов, 
отсортированный по убыванию суммы баллов, набранные суммы и занятые места. 
В данном случае программа должна вывести 
Иванов Сергей 221 1 
Сидоров Юрий 221 1 
Петров Антон 218 2

### Алгоритм решения

Считываем параметры N (количество спортсменов) и M (виды спорта), а затем построчно данные каждого участника

Для каждого спортсмена рассчитываем общую сумму набранных баллов путем суммирования элементов массива результатов

Сохраняем объекты в список и выполняем их сортировку по убыванию суммы баллов с помощью компаратора (IComparer<Athlete>)

Распределяем места с учетом возможного равенства баллов у разных участников

Выводим итоговую таблицу в требуемом формате

# Задание 7

## Задача 11

### Текст задачи

Унарные операции: 
! вычислить длину диапазона, результатом должно быть вещественное 
число 
++ расширить отрезок на 1 вправо и влево 
Операции приведения типа: 
int (неявная) – результатом является целая часть координаты х; 
double(явная) – результатом является координата y. 
Бинарные операции: - LineSegment целое число (левосторонняя операция, уменьшается 
координата х); - целое число LineSegment (правосторонняя операция, уменьшается 
координата y); 
< LineSegment d – результат равен true, если отрезки пересекаются, и false
в противном случае. 

### Алгоритм решения

Перегружаем унарную операцию ! для вычисления модуля разности между концом и началом отрезка

Перегружаем унарный инкремент ++ для расширения отрезка: уменьшаем координату x на 1 и увеличиваем координату y на 1

Реализуем операции приведения типа: неявную к int (возвращает целую часть от x) и явную к double (возвращает координату y)

Перегружаем бинарные операции вычитания - для уменьшения соответствующих координат на заданное целое число с левой и правой сторон

Перегружаем бинарную операцию < для проверки пересечения двух отрезков с возвратом логического значения bool
